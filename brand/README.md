# Semiglobe brand

Semiglobe products are built on [Material Design 3](https://m3.material.io/).

| Piece | File | Notes |
| --- | --- | --- |
| Mark | [`semiglobe-mark.svg`](semiglobe-mark.svg) | Half a globe above a curve. Uses `currentColor`. |
| Avatar | [`avatar.png`](avatar.png) | 1000 × 1000 px, white mark on `primary`. |
| Tokens | [`tokens.json`](tokens.json) | MD3 color roles for light and dark, type and shape scale. |

- **Color:** generated from seed `#1F5FD6` with Google's Material Color Utilities (`SchemeFidelity`).
- **Type:** Google Sans Flex (SIL Open Font License 1.1).
- **Shape:** the MD3 corner scale, with `extraLargeIncreased` (32 px) on hero surfaces.
